1. WTO และ FTA

คำสำคัญ

คำความหมาย
International Tradeแลกเปลี่ยนสินค้า/บริการระหว่างประเทศ (ส่งออก-นำเข้า)
Open Economyเศรษฐกิจที่เชื่อมโยงกับต่างประเทศ
Specializationผลิตสิ่งที่ประเทศมีความชำนาญ
MFNไม่เลือกปฏิบัติระหว่างประเทศคู่ค้า
NT (National Treatment)สินค้านำเข้าที่เข้าตลาดแล้วต้องไม่เสียเปรียบสินค้าในประเทศ
Transparency / Fair Competition / Dispute Settlement / S&Dโปร่งใส · แข่งขันเป็นธรรม · ระงับข้อพิพาท · ยืดหยุ่นให้ประเทศกำลังพัฒนา
จำ: MFN = ประเทศ vs ประเทศ · NT = สินค้านำเข้า vs สินค้าในประเทศ

WTO vs FTA

WTOFTA
ลักษณะกรอบกติการะหว่างสมาชิกความตกลงระหว่างภาคี
เป้าหมายกติกากลาง ความเป็นธรรมสิทธิประโยชน์ตามเงื่อนไข
การใช้สิทธิไม่ใช่สิทธิภาษีพิเศษจาก FTAตรวจ HS Code → ROO → ขั้นตอนใช้สิทธิ
มี FTA ≠ ทุกสินค้าภาษี 0% ต้องตรวจพิกัด ตารางภาษี และ ROO

ทดลอง: Trade Openness

Trade Openness = [(Exports + Imports) / GDP] × 100%

2. มาตรการการค้าและการแข่งขัน

มาตรการที่ควรรู้

Tariffภาษีศุลกากรสินค้านำเข้า
Quotaกำหนดปริมาณนำเข้า
Subsidyเงินอุดหนุนผู้ผลิต (ต้องดูกติกาการค้า)
Dumpingขายต่างประเทศต่ำกว่าค่าปกติตามนิยามกฎหมาย อาจถูกตอบโต้เมื่อครบเงื่อนไข
Exchange Controlsควบคุมการแลกเปลี่ยนเงินตรา
TRQในโควตาภาษีต่ำ ส่วนเกินภาษีสูง
Green / Blue / Amber Boxยกเว้นพันธกรณีลดอุดหนุน / เชื่อมโครงการจำกัดผลิต / อาจบิดเบือนการค้า มีพันธกรณี
TRQ ไม่ได้แปลว่านำเข้าไม่จำกัดในภาษีต่ำ ต้องดูปริมาณและอัตราใน/นอกโควตา

กรณีศึกษา Cost Gap: กระเทียมไทย–จีน

Cost Gap = [(ต้นทุนไทย − ต้นทุนคู่แข่ง) / ต้นทุนไทย] × 100
63% คือช่องว่างต้นทุน ไม่ใช่กำไรที่เพิ่มขึ้น · แนวแก้: สร้างความต่าง (GAP, Organic, GI, Traceability) และลดต้นทุน (เทคโนโลยี รวมกลุ่ม Scale Economies)

กองทุนปรับโครงสร้างการผลิตภาคเกษตร

Grant = เงินจ่ายขาด (อบรม ถ่ายทอดความรู้ ระบบ) · เงินยืมปลอดดอกเบี้ย = ต้องคืน (ทุนหมุนเวียน เครื่องจักร อุปกรณ์แปรรูป) · ต้องชี้ให้เห็นว่าผลผลิตที่เพิ่มจะขายใคร และโครงการยั่งยืนอย่างไร

3. ROO และการคำนวณถิ่นกำเนิด (ข้อสอบข้อ 1)

เกณฑ์ถิ่นกำเนิด

ROOกฎตัดสินถิ่นกำเนิดเพื่อพิจารณาสิทธิ FTA
WOได้มา/ผลิตทั้งหมดในประเทศ เช่น ทุเรียนปลูกและเก็บเกี่ยวในไทย
STแปรสภาพอย่างเพียงพอ
CTCเปลี่ยนพิกัดศุลกากร: CC=2 หลัก (Chapter) · CTH=4 หลัก (Heading) · CTSH=6 หลัก (Subheading)
RVCสัดส่วนมูลค่าตามกฎถิ่นกำเนิด
C/Oหนังสือรับรองถิ่นกำเนิด
การเปลี่ยนพิกัดต้องตรงระดับที่กฎเฉพาะรายสินค้ากำหนด

ตัวอย่างที่ 1: วัตถุดิบนำเข้าต้อง ≤ 40% ของ FOB

น้ำตาล 15 + กรดซิตริก 5 + กระป๋อง 7 + ฉลาก 3 = 30 บาท, FOB 100 บาท

1รวมวัตถุดิบนำเข้า = 30
2สัดส่วน = (30/100) × 100 = 30%
3เทียบเกณฑ์: 30% ≤ 40% → ผ่าน

ตัวอย่างที่ 2: มูลค่าในประเทศ (RVC) ต้อง ≥ 40% ของ FOB

มะม่วงและวัตถุดิบหลัก 20 + ค่าแรง 20 + สาธารณูปโภค 10 = 50 USD, FOB 100 USD

1รวมมูลค่าในประเทศ = 50
2RVC = (50/100) × 100 = 50%
350% ≥ 40% → ผ่าน
“เพดานนำเข้า” กับ “ขั้นต่ำในประเทศ” เป็นคนละเงื่อนไข ใช้สูตรและเกณฑ์เฉพาะ FTA ตามโจทย์

ทดลอง: เครื่องคำนวณ ROO

ขั้นตอนใช้สิทธิ FTA

1) ตรวจ HS Code → 2) ตรวจตารางภาษี/ความตกลง → 3) ตรวจ ROO → 4) รวบรวมหลักฐานวัตถุดิบและการผลิต → 5) เตรียม C/O → 6) ยื่นใช้สิทธิให้ตรงเงื่อนไข

โครงคำตอบอัตนัยข้อ 1

นิยาม ROO → เลือกเกณฑ์ (WO/ST/CTC/RVC) → เขียนสูตรและหน่วย → แทนค่าทุกขั้น → เทียบเกณฑ์ → สรุปผลและหลักฐาน C/O

4. กลยุทธ์เข้าสู่ตลาดและการลงทุน (ข้อสอบข้อ 2)

ผู้ส่งออก 5 ประเภท

ประเภทแนวทางข้อควรระวัง
Copycatเลียนแบบต้นแบบเข้าเร็ว แต่เสี่ยงทรัพย์สินทางปัญญา/แข่งราคา
Leaderพัฒนาสินค้า/Know-how เองสร้างความต่างได้ ทุนสูง
Niche Marketเจาะกลุ่มเฉพาะมูลค่าต่อหน่วยสูง ตลาดจำกัด
Development of Existingปรับสินค้าเดิมให้เหมาะตลาดปรับตามวัฒนธรรม มาตรฐาน กฎ
Ethical Innovative Imitationต่อยอดต้นแบบด้วยนวัตกรรมเคารพทรัพย์สินทางปัญญา

การเลือกกลุ่มตลาด

Mass = ตลาดวงกว้าง · Segmented = แบ่งกลุ่ม (ผู้บริโภค ร้านอาหาร/โรงแรม ผู้จัดจำหน่าย) · Niche = เฉพาะกลุ่ม (อินทรีย์/พรีเมียม)

รูปแบบเข้าสู่ตลาด: ข้อดี-ข้อเสีย

รูปแบบข้อดีข้อเสีย
ส่งออกโดยตรงคุมลูกค้าและการสื่อสารได้มากต้นทุนสูง ต้องรู้ตลาด/เอกสาร
Licensingขยายผ่านการให้สิทธิคุมการใช้สิทธิและคุณภาพ
Franchiseขยายรูปแบบธุรกิจคุมมาตรฐานผู้รับสิทธิ
Contract Manufacturingไม่ต้องสร้างโรงงานเองคุมคุณภาพ/สัญญา
FDIคุมการดำเนินงานได้มากทุนสูง เสี่ยงโดยตรง
Joint Ventureแบ่งทุน ใช้พันธมิตรท้องถิ่นขัดแย้งอำนาจ/ผลประโยชน์

ทดลอง: ตัวช่วยเลือกกลยุทธ์ (แนวคิดตามเกณฑ์ในสรุป)

เกณฑ์เลือก + แผนระยะยาว

พิจารณา: ขนาดตลาด/คู่แข่ง/ช่องทาง · เงินทุน ประสบการณ์ บุคลากร การควบคุม · มาตรฐาน กฎระเบียบ โลจิสติกส์ ความเสี่ยง

แผน: ทดลองตลาด → พัฒนาสินค้า/มาตรฐาน → ขยายช่องทาง → เพิ่มกำลังผลิต → ลงทุนเมื่อพร้อม

โครงคำตอบข้อ 2

สินค้า+ตลาดเป้าหมาย → วิเคราะห์ลูกค้า/คู่แข่ง/มาตรฐาน/ต้นทุน/ช่องทาง → เปรียบเทียบ ≥ 2 รูปแบบ → เลือกพร้อมเหตุผล → แผนระยะยาว

5. อัตราแลกเปลี่ยน

กฎจำจากมุมธนาคาร

สถานการณ์อัตราเหตุผล
ผู้ส่งออกขายเงินตราต่างประเทศให้ธนาคารอัตราซื้อ (Buying)ธนาคารซื้อ
ผู้นำเข้าซื้อเงินตราต่างประเทศจากธนาคารอัตราขาย (Selling)ธนาคารขาย
ถ้าอัตราเป็นบาทต่อ 100 JPY ต้องคูณ/หาร 100 ให้ถูก

ทดลอง: แปลงสกุลเงิน

ทดลอง: ส่งออกข้าว 10,000 USD / นำเข้าปุ๋ย 5,000 USD

รายรับเพิ่มไม่ได้แปลว่ากำไรเพิ่ม ต้องหักต้นทุนวัตถุดิบนำเข้าและต้นทุนอื่น

ระบบอัตราแลกเปลี่ยน: Free Floating (ตลาดนำ) · Managed Float (ธนาคารกลางดูแล) · Soft Peg (ผูกแบบอ่อน) · Fixed (คงที่ แทรกแซงสูง)

6. ตลาดส่งออก มาตรฐาน โลจิสติกส์ ความเสี่ยง

เช็กลิสต์ความพร้อมส่งออก (ติ๊กเพื่อทดสอบตัวเอง)

ความเสี่ยงสำคัญ (กดเพื่อดู)

ต้นทุนแข่งขันเปรียบเทียบกับคู่แข่งและลดช่องว่าง
FTA/การนำเข้าเตรียมคุณภาพและความแตกต่างเพื่อแข่งขัน
ตลาดตรวจลูกค้า ช่องทาง กำลังซื้อ
มาตรฐานตรวจข้อกำหนดปลายทางก่อนส่งออก
โลจิสติกส์ต้นทุนรวบรวม ขนส่ง ส่งมอบ
อัตราแลกเปลี่ยนผลต่อรายรับ-รายจ่ายเป็นบาท
ทรัพย์สินทางปัญญาหลีกเลี่ยงการละเมิด กำหนดสิทธิให้ชัด
เอกสารสรุปไม่ได้ลงรายละเอียด Incoterms หรือประกันภัย ให้ตรวจกับสไลด์ต้นฉบับ
